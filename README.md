# Aman Shorey – Personal Portfolio

A modern, interactive portfolio website showcasing my professional experience, education, leadership roles, and technical development.

🌐 Live Site: https://amanshorey.com  
📍 Based in Dublin, Ireland


## Features

🎨 Interactive Landing Page  
Dark-themed, premium UI with a subtle animated background featuring slow-moving comet-style particles and smooth transitions.

💼 Professional Experience Timeline  
Clean vertical timeline highlighting roles across commercial operations, wealth management, insurance, telecom sales, and finance.  
Each role includes structured summaries and external company links with dynamic hover effects.

🎓 Education & Qualifications  
Academic background including Trinity College Dublin (BESS), Institute of Education, and St. Andrew’s College.  
Includes certifications, leadership positions, and language proficiency.

🌍 International Experience  
One-month French exchange programme enhancing conversational fluency and cultural awareness.

🖱 Premium UI Interactions  
Smooth hover transitions, dynamic colour-linked timeline dots, interactive external links, and subtle animated background effects.

📱 Fully Responsive Design  
Optimised for desktop, tablet, and mobile devices.

This site is deployed using GitHub Pages.

Production builds are automatically served from the main branch.  
Custom domain configured via DNS (Blacknight) and linked to GitHub Pages.


## Design Philosophy

This portfolio is designed to feel:

• Professional yet modern  
• Clean and structured  
• Commercially aware and data-driven  
• Subtle, premium, and performance-focused  

The goal is to combine strong commercial presence with polished technical execution.
